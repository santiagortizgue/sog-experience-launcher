# SOG Experience Modpack Metadata

This repository maintains the Packwiz index metadata and manifests for the SOG Experience Minecraft modpack.

## Specifications
- **Minecraft**: `1.21.1`
- **Mod Loader**: `NeoForge 21.1.250`
- **Format**: Packwiz 1.1.0

## 🔒 Internal Documentation & Context
For workspace developers and server maintainers, detailed roadmaps, setup guides, and export procedures are kept in the local `context/` directory (intentionally untracked by Git via `.gitignore` to prevent leaking server details or installation flows publicly):
- `context/development_plan.md` — Phased roadmap, technical workflow, and architecture milestones.
- `context/export_and_setup_guide.md` — Admin instance export procedure and client synchronization guide.
- `context/mod_list_from_prism.md` — Source mod list reference and upstream repository URLs.
