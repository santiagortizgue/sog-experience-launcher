# 🚀 SOG Experience Launcher

This repository hosts the auto-updating modpack configuration for the **SOG Experience** Minecraft Server, a private personal server. It leverages the open-source modpack manager **Packwiz** integrated directly into **Prism Launcher** to automatically distribute and synchronize mods, configuration files, FTB quests, and shared waypoints to player clients before launching the game.

## 🛠️ Technical Stack

- **Minecraft Version**: `1.21.1`
- **Mod Loader**: `NeoForge` (Version `21.1.218`)
- **Modpack Synchronization**: `Packwiz` (using `pack.toml` and `index.toml`)
- **Target Launcher**: `Prism Launcher` (via `packwiz-installer-bootstrap.jar` pre-launch command integration)
